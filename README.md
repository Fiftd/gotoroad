# gotoroad — 가고 싶은 길

서울 지하철 노선을 여행하는 Python/Pygame 게임입니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행하세요.

```sh
python -m pip install pygame Pillow
python main.py
```

저장 데이터(`save.json`)와 개인 설정(`settings.json`)은 실행 중 생성되며 Git에 포함하지 않습니다.
