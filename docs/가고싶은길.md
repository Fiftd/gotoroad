#
가고 싶은 길

수도권이 아닌 사람들에게 대중교통을 이용에 있어 익숙해지기 위해 각 역, 정류장 등등 대중교통을 활용한 이동 공간에 게임을 도입해 친근하게 익숙해질 수 있도록 고안.

1. 지하철
 수도권에 지하철을 필수불가결로 사용에 익숙해질 필요가 있음.
각 호선의 대표역에서 출발. 스페이스 바 홀딩 | 마우스 왼쪽 홀딩 으로 지하철에 에너지를 주입. 버튼을 떼는순간 축적된 에너지에 비례하여 역을 뚫는 게임. 역은 최초 진입 시 파괴되면서 해당 역 이름이 큰 글씨로 강조하며 역을 강조시킴. 환승역은 해당 역에 연결된 호선을 숫자, 화살표로 표기하여 선택 시 전철이 봐뀌며 다시 홀딩, 트리거를 작동.
