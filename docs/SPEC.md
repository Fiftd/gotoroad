# 가고 싶은 길 — 기능 명세서 (gotoroad 리빌딩용)

원본 `gago-road-draft`(읽기 전용)의 기능을 새 구조(`gotoroad/game/...`)의 파일 단위로 정리한 문서.
각 항목의 **원본** 줄은 옮겨 올 때 참고할 원본 위치(파일 › 클래스/함수)다.

- 실행 환경: Python 3.13 + pygame. 창 1280×800, 크기 조절 가능, 60 FPS.
- 기획 원문: `gago-road-draft/가고싶은길.md`

---

## 0. 전체 흐름
  해당 게임은 픽셀 배경.
```
메인 메뉴 ─ 지하철 ─→ 권역 선택 ─ 수도권 ─→ 호선 선택 ─ 호선 클릭 ─→ 지하철 플레이
          ├ 버스 (미구현, 비활성)   ├ 대구/대전/부산권 (미구현)        │  ESC
          ├ 기차 (미구현, 비활성)   └ 뒤로                              └→ 호선 선택으로
          └ 설정 ─→ 설정 ─ 지하철 › ─→ 호선별 표시 on/off
```

- 장면 전환은 `App.go(scene)` 하나로 한다. 각 장면은 `handle(event)`, `update(dt)`, `draw(screen)`를 가진다.
- ESC는 항상 "한 단계 뒤로". 메인 메뉴에서 ESC를 누르면 종료.

### 기획서와 원본 구현의 차이 (결정 필요)
| 항목 | 기획서 | 원본 구현 | 비고 |
|---|---|---|---|
| 게임 제목 | 가고 싶은 길 | 가보는 지하철 | |
| 권역 선택 화면 | 있음 | **없음**(바로 호선 선택) | 새 구조에 `region_select.py` 마련됨 |
| 호선 선택의 on/off 체크박스 | 버튼 옆 체크박스 | 설정 › 지하철 하위 메뉴로 분리 | |
| 설정: 소리, 충격 on/off | 있음 | **없음** | 충격 = 플레이의 흔들림·플래시·불꽃 |
| 설정: 전체 화면 | 없음 | 있음 | |
| 지역동 표시 | 행정구 off면 자동 off | 같음(비활성 처리) | |

## 2. `game/app.py` — App
**원본:** `main.py › App`

- **초기화:** pygame 초기화, 창 생성(1280×800, RESIZABLE), 제목 지정.
- **폰트:** assets/font 'neodgm'을 사용.
  - `font(size, bold=False)` 팩토리를 만들어 모든 장면이 공유한다.
  - 기본 크기: 제목 44, 버튼 26, 작은 글씨 15. 맵에서는 14, 16, 22. HUD는 34(굵게)와 30(굵게).
- **공유 객체:** `map_data`(world), `profile`(save), `settings`(save)
- **루프:** 이벤트 처리 → `scene.handle(e)` → `scene.update(dt)` → `scene.draw()` → `flip` → `tick(60)`
  - QUIT 이벤트가 오면 종료한다.
  - 원본은 dt를 `time.perf_counter`로 따로 쟀다. 새 구조에서는 `clock.tick()`의 반환값을 dt로 쓰고, 상한은 0.05초로 둔다.

### 함수
- **충전 → 에너지:** `charged_energy(charge, mult)`
  - SPACE로 에너지 바를 충전한다(최대 `CHARGE_MAX` 1000).
  - 바가 1000에 닿으면 `mult = uniform(1.0, BONUS_MAX)`를 한 번 뽑는다. 즉 0~30% 추가 에너지
  - 얻는 에너지 = 1000 미만이면 `charge`, 1000이면 `charge × mult` (1000~1300)
- **속도 계수:** `roll_speed_factor()` = `uniform(0.5, 0.8)`. 역을 떠날 때마다(첫 출발 포함) 새로 뽑고, 그 구간 동안 유지한다.
- **속도:** `speed_from_energy(e, factor)` = `e × 0.1 × factor` km/h
  - e ≤ 10이면 0, 상한은 150
  - 예: 1000 J → 50~80 km/h, 1300 J → 65~104 km/h
- 속도가 에너지에 비례하므로 "속도 ×0.75"는 "에너지 ×0.75"와 같다.
- 출발할 수 있는 최소 에너지: `STOP_KMH`(5) ÷ (0.1 × 계수) = 62.5~100 J

> 새로 추가할 것(호선 메뉴 정보): 원본 `main.py › LINE_MENU`
> `(id, 이름, 색, 출발역)` 18개.
> 1→서울역, 2→시청, 3→경복궁, 4→서울역, 5→광화문, 6→공덕, 7→건대입구, 8→잠실, 9→여의도, arex→서울역, gyeongui→용산, gyeongchun→청량리, suinbundang→왕십리, shinbundang→강남, sillim→보라매, ui→신설동, gimpo→없음, seohae→없음.
> 색은 data.json의 값이 우선이다. 출발역이 없으면 "준비 중"으로 표시한다.

## 4. `game/save.py` — 저장

### Profile (`save.json`)
**원본:** `S_StationPlay.py › Profile`
- 필드: `version`, `points`, `unlocked`(id 목록)
- `load()`
  - 파일이 없거나 깨져 있으면 기본값을 쓴다: points 0, unlocked = FREE_LINES.
  - `version`이 `SAVE_VERSION`과 다르면 points만 살리고 해금 목록은 FREE_LINES로 되돌린다.
- `save()`: 실패해도 게임은 계속 진행한다.
- `add(n)`: Point를 더하고 바로 저장한다.
- `is_unlocked(id)`
- `next_price()` = 1000 × (무료가 아닌 해금 수 + 1)
- `buy(id)`: Point가 모자라면 아무것도 바꾸지 않고 False를 돌려준다. 성공하면 차감하고 해금한 뒤 저장한다.

### Settings (`settings.json`)
**원본:** `main.py › App.load_settings / save_settings`
- `districts: bool`(행정구역), `labels: bool`(지역 이름), `lines: {id: bool}`(호선 표시. 없는 키는 True로 본다)
- 형식이 잘못된 값은 무시하고 기본값을 쓴다.
- 기획서 항목을 넣을 경우 추가: `sound`, `impact`

### `line_select.py`
**원본:** `main.py › LineSelect` (원본은 글자 버튼. 새 구조에서는 호선 아이콘으로 바꾼다)

- **아이콘 이미지:** `assets/ui/line_icons/{id}.png`(64×64, 구매함), `{id}_locked.png`(회색, 미구매·준비 중)
  - 개선 노선도 스타일의 원형 기호. 메인전철은 숫자, 나머지는 글자(예: 공항/철도, 신분당)
  - `tools/gen_line_assets.py`로 만든다. 색이나 글자를 바꾸려면 `assets/map/line_types.json`을 고치고 다시 실행한다.
  - 확대할 때는 반드시 `pygame.transform.scale`(nearest)을 쓴다. `smoothscale`을 쓰면 픽셀이 뭉개진다.
- **배치: 4열 × N행 격자** (확정: 종류 구분 없이 `LINE_MENU` 순서대로 4개씩)
  - `LINE_MENU` 순서대로 4개씩 끊어 줄을 만든다. 마지막 줄의 모자란 칸은 비워 둔다(empty). 자리 배열은 항상 4열을 지킨다.
  - 결과: [1 2 3 4] [5 6 7 8] [9 공항 경의 경춘] [수인 신분당 신림 우이] [김포 서해 _ _] = 5줄
  - 칸 크기: `CELL_W` 160 × `CELL_H` 88 (아이콘 64 + 글자 16 + 여백). 격자 전체를 화면 가로 가운데에 둔다.
  - "뒤로" 버튼은 격자 아래 `BACK_GAP`(28) 띄워 가운데에 둔다. 격자 + 간격 + 버튼을 한 덩어리로 세로 가운데 정렬(제목 아래로는 안 올라감).
- **아이콘 상태 판정** (아래 순서로 검사)

  | 조건 | 이미지 | 아이콘 아래 글자 | 클릭 |
  |---|---|---|---|
  | data에 없거나 출발역이 없음 | `_locked` | "준비 중" (회색) | 반응 없음 |
  | 설정에서 꺼짐 | `_locked` | "설정에서 꺼짐" (회색) | 반응 없음 |
  | 해금됨 | 기본 | 호선 이름 | 플레이 시작 |
  | 그 외(미구매) | `_locked` | "구매 : {가격:,} P" (살 수 있으면 초록, 아니면 주황) | 구매 시도 |

- **마우스를 올렸을 때:** 아이콘 둘레에 흰 고리(2px)를 그리고 1.1배로 키운다.
- **호선 선택 → 하단 탭(출발역·도착역)** — 해금된 아이콘을 클릭하면 그 호선이 **선택**(주황 고리)되고 화면 아래에 탭이 열린다.
  - **탭은 늘 보인다.** 호선을 안 골랐으면 테두리 회색, 출발역 목록 = 탈 수 있는(해금·표시) 모든 역(가나다순). 출발역을 고르면 그 역의 탈 수 있는 첫 호선이 자동 선택(`sync_line`). 출발역 전에는 "출발" 버튼 꺼짐. ESC: 호선 선택 해제(한 번 더 → 뒤로).
  - 탭: `출발역` 칸(기본값 = 호선 기본 출발역), `도착역` 칸(기본 없음, 네비게이션용), `출발` 버튼. 부품은 `scenes/station_field.py`(StationField).
  - 칸에 **마우스를 올리면 위로 역 목록이 펼쳐지고**, 항목을 클릭하면 정해진다. 목록 항목은 작은 역 간판(sm)으로 보인다. 휠로 스크롤.
  - **키보드:** 칸을 클릭하거나 Tab으로 들어가 글자를 치면 목록이 걸러진다(앞에서 맞는 역 먼저, 한글 조합 중 글자도 반영). ↑↓ 선택, Enter 확정, Backspace 지우기, ESC 입력 그만.
  - 출발역 목록 = 그 호선의 역(노선 순서), 도착역 목록 = 모든 역(가나다순) + "(없음)".
  - **출발:** `출발` 버튼 / 칸 밖에서 Enter / 같은 아이콘 한 번 더 클릭 → 아래 선택 연출. ESC는 선택 취소(탭 닫기), 선택이 없으면 권역 선택으로.
  - 고른 출발역은 `SubwayPlay(line, start=, dest=)` → `Session(start=)`로 넘어가 시작역(에너지 소진 시 돌아갈 역)이 된다. 도착역은 `SubwayPlay.dest`에 저장(네비게이션에서 사용).
- **선택 연출 (확정: 확인 클릭 없이 자동 진행)** — 출발을 누르면(간판은 하단 탭에서 고른 출발역 기준)
  1. **떠오름 (0~0.25초, `RISE_TIME`):** 아이콘이 제자리에서 화면 중앙으로 이동하며 2배(128×128)로 커진다. ease-out. 나머지 화면은 반투명하게 어둡게 덮는다.
  2. **간판 등장:** 그 자리에 **출발역의 그 호선 간판** `station_signs/lg/{호선}/{출발역}.png`를 **2배**로 그린다.
     - 간판의 호선 기호(64)가 2배로 128이 되어, 떠오른 아이콘과 크기·위치가 정확히 겹친다(기호 중심 = 아이콘 중심).
     - **출발역이 환승역이면**(16개 호선 중 3·5호선을 뺀 14개의 출발역이 환승역) **환승역 간판**(`lg/transfer/{역}`, 검은 테두리)을 쓰고, 기호 자리에서 **호선 기호 → 삼태극 뒤집기**를 한다(`FLIP_TIME` 0.24초).
       - 앞 절반(0.12초): 호선 기호(①)의 가로 폭이 128 → 0으로 납작해진다.
       - 뒤 절반(0.12초): 삼태극(`station_signs/taegeuk_lg.png`)이 가로 폭 0 → 128로 펼쳐진다.
       - 동전 뒤집기처럼 가로 폭만 바꾸므로 회전과 달리 도트가 깨지지 않는다. 뒤집는 동안에는 간판 속 삼태극을 흰 원으로 가리고 그 위에 그린다.
       - 이후 지도 위 작은 간판도 환승역 간판(`sm/transfer`)을 쓴다.
     - 기호 중심 좌표는 `signs.json`의 `lg.badge_center`(간판 안 좌표, 1배 기준 (68, 40)).
  3. **멈춤 (0.3초, `SIGN_HOLD`):** 간판을 그대로 보여 준다. (전체: 떠오름 0.25 + [환승역이면 뒤집기 0.24] + 멈춤 0.3)
  4. **줌 아웃 → 플레이:** 플레이 장면으로 넘어가서, 카메라가 출발역을 가운데에 둔 채 `INTRO_ZOOM`(3.0)에서 `ZOOM`(0.9)으로 줄어든다(`INTRO_TIME` 0.5초, ease-out). 그동안 큰 간판(2배)은 출발역 화면 위치로 줄어들며 사라지고, 지도 위의 작은 간판(sm)이 남는다.
  - 연출 중에는 입력을 받지 않는다.
- **구매:** 미구매 아이콘을 클릭하면 `buy()`를 시도하고, 2.5초 동안 메시지를 띄운 뒤 상태를 다시 계산한다.
  - 성공: "{이름} 해금! (-{가격} P)". 그 아이콘이 회색에서 기본 이미지로 바뀐다.
  - 실패: "Point 부족 (보유 x / 필요 y)"
- 제목 아래에 "보유 Point {n} P"를 주황색으로 표시한다. 메시지는 화면 아래에 흰 박스로 띄운다.

## 7. `game/stations/` — 역 종류

원본에는 클래스가 하나(`game_map.py › Station`)뿐이고, 종류는 플레이 로직의 조건문으로 나뉜다. 새 구조에서는 기획서대로 나눈다.

| 클래스 | 판정 (원본 조건) | 도착 시 동작 |
|---|---|---|
| `Station` | 기본 | 이름, 좌표, 구·동, 소속 호선, `visited`(최초 진입 여부), `label_spot`. 화면용 상태: `hover`, `selected`, `pulse`(1→0, 프레임마다 −0.03) |
| `StartStation` | 선택한 호선의 출발역 | 시작 위치. 에너지가 바닥나면 이 역으로 돌아옴. 화면에 "출발" 태그와 노란 고리 |
| `SwitchStation` | 현재 호선에서 `next_options`가 2개 이상 (`switch` 목록에 호선이 있음) | pick 상태가 되어 ← →로 방향 선택. 노란 마름모 표시 |
| `InterchangeStation` | 이용 가능한 소속 호선이 2개 이상 (`transfer`) | pick 상태가 되어 Q~F로 호선 변경 |

- 한 역이 환승역이면서 갈림길일 수 있고, 시작역이 환승역일 수도 있다. 그래서 상속보다 "역할" 판정으로 처리하는 편이 안전하다.
  - 예: `station.is_interchange()`, `line.is_switch(station)`
  - 클래스를 나눌 경우: 판정 기준을 `map_data` 로드 시점에 정하고, 시작역 여부는 플레이 시작 때 붙인다.
- `hit(wx, wy, zoom)`: 반경 `max(11+4, 12/zoom)` 안에 있으면 맞은 것으로 본다.

## 8. `game/play/` — 규칙 (그리기 없음)

### 상태 기계 (`session.py`)
**원본:** `S_StationPlay.py › StationPlay`

```
idle ──SPACE 누름──→ charging ──SPACE 뗌──→ run ──도착──┬→ crash (첫 진입) ──0.9s──┐
 ▲  (방향이 정해져 있을 때)                 │            └→ mini  (재방문) ──결과 1s─┤
 │                                         └ 속도<2 → 소진(reset)                   ▼
 │                                                              갈림길·환승역? → pick (3s) ─┐
 └──────────────────────────── 소진 ───────────────────────────── 아니면 바로 다음 구간 run ◀┘
```

- **세션 상태**
  - `cur`, `prev`, `line_id`, `home_line_id`
  - `E`(에너지 J), `state`
  - `charge`, `charge_mult`, `speed_factor`(이번 구간의 속도 계수 0.5~0.8)
  - `trk`, `s`(구간 진행 m), `target`, `pos`, `angle`
  - `opts`(다음 역 후보, x좌표 오름차순 = 화면 왼쪽부터), `choice`, `is_switch`, `tlines`(환승 후보)
  - `visited`(순서 목록과 집합), `timer`, `mini`
  - 연출: `shake`, `flash`, `sparks`, `toasts`, `crash_text`
- **reset(start, keep_visited)**
  - 시작 호선으로 되돌리고, `cur=start`, `prev=None`, `E=0`, `state=idle`
  - `keep_visited`가 아니면 visited를 [start]로 초기화
  - `heading=None`(아직 달린 적 없음), `just_transferred=False`
  - opts와 기본 방향을 계산한다(아래 규칙 1).
- **_set_options**
  - opts = `next_options(cur, prev)`. 비어 있으면(종점) `[prev]`로 되돌아간다.
  - opts는 역의 x좌표 오름차순으로 정렬한다(화면 왼쪽부터). 그래서 **마지막 인덱스가 오른쪽(→)**이다.
  - **기본 방향(choice) 규칙** — 항상 기본값을 하나 골라 두고, 플레이어는 ← →로 바꿀 수 있다.

    | 순서 | 상황 | 기본값 |
    |---|---|---|
    | 1 | 후보가 1개 | 그 후보 |
    | 2 | 환승 직후(`just_transferred`) | **기존 호선에서 달리던 방향**(`heading`)과 가장 가까운 후보. `heading`이 없으면(시작역에서 바로 환승) 오른쪽 |
    | 3 | 시작역(출발 전, `heading is None`) | **오른쪽**(x가 가장 큰 후보) |
    | 4 | 갈림길(`prev`가 있고 후보 2개 이상) | **오른쪽** |

    - 위에서부터 처음 맞는 줄을 적용한다.
    - **방향 비교:** 후보마다 `현재 역 → 후보 역` 각도를 구하고, `heading`과의 차이가 가장 작은 것을 고른다. 차이 = `abs((a − heading + π) % 2π − π)`
    - `heading`은 역에 도착할 때 마지막 구간의 진행각(`angle`)으로 저장한다.
    - 환승역에서 호선을 바꾸지 않고 그대로 지나가면 환승 규칙이 아니라 3·4번 규칙을 따른다.
    - "오른쪽"은 x가 가장 큰 후보다. 남북으로 달리는 노선에서는 오른쪽 후보도 현재 역보다 왼쪽에 있을 수 있다(칩에는 "<-"로 표시됨).
- **방향 선택 (← →)**
  - idle이나 pick 상태이고, 정차 중이며, 후보가 2개 이상일 때만 받는다.
  - 후보 2개: ←이면 0, →이면 1
  - 3개 이상: 현재 선택(없으면 가운데)에서 ±1
- **SPACE 누름**
  - idle이고 방향이 정해져 있으면 charging으로 간다(charge=0, mult=1).
  - 방향이 없으면 토스트 "← → 로 가는 방향을 먼저 고르세요"
  - pick 상태면 선택을 확정한다.
- **charging(dt)**
  - `charge += bar_speed(charge) × 444 × dt`, 상한 1000
  - 1000에 처음 닿을 때 `mult = uniform(1.0, 1.3)`
  - `bar_speed(c)` = c ≤ 700이면 1.5, 아니면 `max(0.3, 1.5 − 0.1×(c−700)/50)`
- **SPACE 뗌**
  - `E += charged_energy(charge, mult)`
  - 구간을 시작하기 전에 `speed_factor = roll_speed_factor()`를 뽑는다.
  - 속도가 5 km/h 미만이면 idle로 돌아간다.
  - 아니면 구간을 시작하고 run으로 간다.

### `energy.py`
- 위의 충전 계산, `speed = speed_from_energy(E, speed_factor)`, 소모 `E −= 60 × 이동m/1000`

### `train.py` — 이동과 도착
- **run(dt)**
  - 속도가 `STOP_KMH`(5) 미만이면 소진 처리한다.
  - 아니면 이동 거리 `m = v/3.6 × dt × 300`만큼 E를 소모하고 s를 늘린다. 위치와 각도는 `trk.at(s)`
  - `s ≥ 구간 길이`가 되면 도착 처리한다.
- **도착**
  - `prev, cur = cur, target`, `trk=None`, 역 `pulse=1`
  - 첫 진입이면
    - Point +200, visited에 추가
    - `E ×= 0.75` (속도도 ×0.75)
    - crash 상태 0.9초, shake 0.55, flash 1.0
    - 불꽃 34개: 무작위 각도, 속도 90~330, 위쪽으로 −80, 수명 0.4~0.9초, 중력 260
    - 문구 "{역} 첫 도착! 속도 ×0.75"
  - 재방문이면 Point +20, 미니게임 시작
  - 어느 쪽이든 토스트 "+N P"
- **crash 또는 mini가 끝난 뒤**
  - opts와 tlines를 다시 계산한다.
  - 갈림길이나 환승역이면 pick 상태(3초), 아니면 바로 출발한다.
- **pick(dt):** 시간이 다 되면 출발한다. choice가 없으면 0번을 고른다.
- **출발:** `speed_factor`를 새로 뽑은 뒤, 속도가 `STOP_KMH`(5) 이상이면 다음 구간 run, 아니면 소진
- **소진**
  - 시작역으로 reset(keep_visited=True)
  - 카메라를 시작역으로 옮기고 flash 0.6
  - 토스트 "에너지 소진! 시작역으로 돌아갑니다"
- **환승** (정차 중, idle이나 pick 상태, tlines가 2개 이상일 때)
  - `tlines` = 현재 역의 소속 호선 중 이용 가능한 것(데이터 순서). Q W E R A S D F 순서로 대응한다.
  - 대응하는 호선이 없으면 무시한다.
  - 지금 타고 있는 호선이면 토스트 "{호선} 탑승 중"
  - 잠긴 호선이면 토스트 "잠긴 호선: {호선} (호선 선택에서 해금)"
  - 갈아탈 수 있으면
    - 호선을 바꾸고 Track을 다시 만든다.
    - `prev=None`, `just_transferred=True`로 두고 `_set_options`를 다시 한다. 기본 방향은 위 규칙 2(기존 호선의 진행 방향)
    - flash 0.5, 토스트 "환승 → {호선}"(호선 색)
    - pick 상태였다면 타이머를 `PICK_TIME`으로 다시 채운다.
    - 다음 역을 향해 출발하면 `just_transferred=False`
  - 에너지와 지나간 역 기록은 그대로 이어진다.

### `minigame.py`
- **시작**
  - Q~F 중 2~4개를 중복 없이 뽑는다.
  - 제한 시간 = 1.0 + 0.8×개수
  - 0.15초 동안은 입력을 받지 않는다(arm).
- **입력**
  - Q~F가 아닌 키는 무시한다.
  - 차례에 맞는 키면 다음 칸으로 넘어가고, 마지막 키까지 맞히면 성공이다.
  - 틀린 키를 누르면 즉시 실패한다.
- **시간:** arm이 끝난 뒤부터 줄어든다. 0이 되면 실패한다.
- **결과**
  - 성공: E +200, 토스트 "+200 J"
  - 실패: 토스트 "MISS"
  - 결과를 1초 동안 보여준 뒤 "끝난 뒤" 처리로 넘어간다.

## 9. `game/render/` — 그리기

### `camera.py`
**원본:** `game_map.py › Game.fit / to_world / to_screen / focus`, `StationPlay._smooth_zoom / _follow`
- 상태: `zoom`, `ox`, `oy`
- `to_screen(x,y) = (x·zoom+ox, y·zoom+oy)`이고 `to_world`는 그 역변환
- `fit()`: 맵 전체가 화면에 들어오게 맞춘다. `focus(x,y)`: 그 점을 화면 가운데에 둔다.
- **플레이용 동작**
  - 목표 확대 배율은 환승 선택 중이면 2.0, 아니면 base_zoom(기본 0.9)
  - 화면 중앙을 기준으로 `1−exp(−6dt)` 비율만큼 다가간다.

  - 출발 전에 드래그했다면(free_cam) 그 시점을 유지하고, 달리기 시작하면 다시 열차를 따라간다.
- 흔들림: `shake > 0`이면 진폭 `10×shake/0.55`로 무작위 오프셋을 준다. 맵, 열차, 불꽃에만 적용하고 HUD에는 적용하지 않는다.

     | 종류 | 호선 | 모양 |
     |---|---|---|
     | 메인전철 `main` | 1~9호선 | 굵은 단색 |
     | 도시철도 `city` | 신분당선 | 이중선(가운데 흰 줄) |
     | 경전철 `light` | 신림선, 우이신설선, 김포골드라인 | 가는 단색 |

     서울시 발표 자료에는 노선별 분류 목록이 없어서, 위 표는 실제 운영 주체와 성격을 기준으로 정한 것이다. 바꾸려면 json만 고치면 된다.

     - 세로 = 선의 단면(흰 테두리 포함). 가로 = 반복 단위. 선을 따라 가로로 반복해 찍는다.
     - 검정(0,0,0)은 호선 색으로 바꿀 자리, 흰색은 흰색 그대로, 투명은 비운다.
     - 호선 색 입히기: 타일을 복사해 `pygame.PixelArray(tile).replace((0,0,0), line.color)`로 바꾼다. 호선마다 한 번만 만들어 캐시한다.

     - **A. 겹쳐 그리기 (빠름, 권장).** 타일과 같은 결과를 `pygame.draw.lines`를 여러 번 써서 만든다. 굵기는 맵 px이고 화면에서는 `×zoom×1.6`을 곱한다.

       | 종류 | 1. 흰색 | 2. 호선 색 | 3. 흰색 덧그리기 |
       |---|---|---|---|
       | main | 14 | 10 | 없음 |
       | city | 14 | 10 | 가운데 4 (이중선이 됨) |
       | light | 8 | 4 | 없음 |
       | trunk | 14 | 10 | 가운데 2, 점선(6 그리고 6 띄움) |

       점선은 경로 길이를 따라 걸으며 6만큼 그리고 6만큼 띄운다. 구간이 바뀌어도 남은 길이를 이어서 센다.
     - **B. 타일 찍기 (정확한 픽셀 모양).** 구간마다 길이만큼 타일을 가로로 이어 붙인 띠를 만들고, 구간 각도로 `rotate`해서 구간 중심에 blit한다. 줌 단계별로 캐시하지 않으면 느리다.
   - 범례(H키, 설정 화면)에는 `assets/ui/line_types/{type}.png`(160×28, 종류 대표색 견본)를 쓴다.
   - 역 배지(환승역의 호선 표시)도 한 글자 약칭 대신 `line_icons/{id}.png`를 작게(배지 크기로 nearest 축소) 써도 된다.

### 네비게이션.
출발, 도착역 지정해서 해당 노선에 맞게 이동 할 수 있게 네비게이션 활성화.

**구현됨.** 호선 선택 탭에서 도착역을 고르면 켜진다(출발역과 같거나 "(없음)"이면 꺼짐).
- `world/route.py` › `find_route(map, cur, line_id, dest, allowed, prev)` — 다익스트라. 상태 = (역, 호선, 직전 역).
  - 이웃 역: 비용 = 선로 `length_m`. 갈림길(switches)·종점 되돌아감은 Session 과 같은 규칙.
  - 환승: 같은 역에서 다른 호선으로, 비용 `NAV_TRANSFER_COST`(1500 m). 해금 + 운행 중 호선만. 연속 환승 없음.
  - 결과 `[(역, 호선), ...]`, 못 가면 None.
- `play/nav.py` › `Nav(map, profile, dest)` — 서 있을 때 (역, 호선, 직전 역)이 바뀌면 경로 재탐색(길을 벗어나도 다시 안내).
  `next_hop()` → `("go", 역)` / `("transfer", 호선)`, `remaining()` 남은 역 수, `transfers()`, `segments()`.
- `SubwayPlay` — `update_nav()`: 역에 서서 선택지가 새로 생기면 경로 쪽 방향을 **기본 선택**으로 골라 줌(그 뒤 ←→ 는 플레이어 몫).
  `draw_route()`: 경로를 빨간(255,0,0) **불투명** 띠로 호선 위에 덮어 그림 + 목적지 핀.
- **도착 화면** — 목적지에 서면 세션을 멈추고(`state = "arrived"`), 크래시 연출이 끝나면 `draw_result()`:
  "도착", 역 이름, 시간("n분 nn초", 실제 시계 `pygame.time.get_ticks()` 기준, 장면 시작~도착 순간, 에너지 소진 후에도 이어서 셈), 지나온 역 수와 순서(`trip`, 에너지 소진 시 출발역부터 다시 기록, 같은 역 재방문 포함, 길면 앞을 "..."로 줄임).
  버튼: **다시하기**(Enter / R, 같은 호선·출발역·도착역으로 새 `SubwayPlay`) / **호선 선택**(ESC 와 같음).
- `Hud.draw_nav` — 위 가운데 패널: 목적지 / "다음: ○○ 방향" 또는 "환승: ○호선 (W 키)" / 남은 역·환승 수. 길이 없으면 빨간 안내.
  환승 링에서 추천 호선 칩에 빨간(NAV_COLOR) 테두리.
- 잠긴 호선 알림: 잠김을 무시한 최단 경로도 함께 찾아(`Nav.need`), 거기에 잠긴 호선이 있으면 왼쪽 상태 패널 아래에 "해금이 필요해요" + 호선 목록(`Hud.draw_need`).
  해금 호선만으로 갈 길이 없으면 네비 패널에 "잠긴 호선 때문에 갈 수 없어요".
- config: `NAV_TRANSFER_COST`, `NAV_COLOR`, `NAV_ALPHA`.

### 소리 (구현됨)
`game/sound.py` › `Sound(setting)` = `app.sound`. 파일 `assets/sound/{이름}.mp3`. 설정 '소리' 꺼짐이면 무음, 장치·파일이 없어도 게임은 계속.
- 배경음악: 로비 장면 `play_bg_piexlfunk`, 플레이 `lobby_bg`(파일 이름이 서로 바뀌어 있음)(`SubwayPlay.music = "play"`). `App.go` 에서 장면마다 고름(같은 곡이면 이어짐).
- 로비: 버튼 `button_click`(뒤로가기 포함), 설정 토글 `on_off`, 초기화 실행 `reset`, 출발(출발 버튼·Enter·아이콘 재클릭·다시하기) `start`.
- 플레이: Q~F·← → 입력이 실제로 받아질 때 `qwer_sound`, 첫 방문 크래시 `crash`, 역 도착마다 `jump`, 미니게임 실패 `fail`,
  충전 중 반복 `charging`(놓으면 멈춤), 네비 길 없음 `error`(새로 찾았을 때 한 번).
- config: `SOUND_DIR`, `SFX_VOLUME` 0.7, `MUSIC_VOLUME` 0.4.
